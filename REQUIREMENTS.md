# Техническое задание: typecode

## 1. Функциональность

typecode - это интерактивный TUI-тренажёр слепой печати для программистов, запускаемый в терминале Linux.

### Задачи, которые решает продукт

- Развитие навыка слепой печати применительно к программному коду, а не к обычному тексту.
- Формирование мышечной памяти на синтаксис конкретных языков программирования.
- Отработка специальных символов: `{}`, `[]`, `()`, `<>`, `;`, `->`, `=>`, `::`, `&&`, `||`, `\n`, `\t`.
- Отслеживание прогресса между сессиями через историю WPM и точности.
- Выявление конкретных символов, на которых пользователь чаще всего ошибается.

### Сценарии использования

**Сценарий 1 - Изучение раскладки.**
Пользователь выбирает набор базовых уроков (Latin): домашний ряд, верхний ряд, нижний ряд, цифры, символы - и проходит их последовательно для освоения позиций клавиш.

**Сценарий 2 - Практика синтаксиса языка.**
Пользователь выбирает язык программирования (C, Python, JavaScript, Bash, Go) и проходит 20 уроков с нарастающей сложностью - от переменных и типов до сложных конструкций.

**Сценарий 3 - Практика на собственном коде.**
Пользователь через пункт Practice > Load File вводит путь к произвольному текстовому файлу на диске и набирает его содержимое.

**Сценарий 4 - Тренировка в режиме Time Attack.**
Пользователь включает режим Timed в настройках, задаёт лимит (15-300 секунд) и отрабатывает скоростной набор с обратным таймером.

**Сценарий 5 - Жёсткий режим.**
Пользователь включает Hardcore - Backspace отключён, исправить ошибку нельзя. Тренирует точность и внимательность.

**Сценарий 6 - Анализ слабых мест.**
После нескольких сессий пользователь открывает Statistics > Weak Spots, видит топ-10 проблемных символов и генерирует персональное упражнение клавишей `G`.

**Сценарий 7 - Визуальная проверка клавиатуры.**
Пользователь открывает Statistics > Heatmap и видит QWERTY-раскладку с цветовой подсветкой: зелёный - мало ошибок, жёлтый - средне, красный - много.

## 2. Формат входных данных

### Файлы уроков

Уроки хранятся в директории `lessons/` в виде обычных текстовых файлов `.txt`.

- Кодировка: UTF-8 (ASCII-подмножество для базовых уроков).
- Содержимое: произвольный текст, который пользователь должен набрать.
- Допустимые символы: печатаемые ASCII (коды 32-126), символ новой строки (`\n`), символ табуляции (`\t`).
- Символ `\n` отображается в тренажёре как `$` и требует нажатия Enter.
- Символ `\t` отображается как `>` и требует нажатия Tab.
- Ограничений на длину файла нет; отображение прокручивается по строкам.

Структура директории уроков:

```
lessons/
  latin/          # 5 базовых уроков (без языковой специфики)
  c/              # 20 уроков C
  python/         # 20 уроков Python
  javascript/     # 20 уроков JavaScript
  bash/           # 20 уроков Bash
  go/             # 20 уроков Go
```

Имя файла урока используется как отображаемое название: дефисы и подчёркивания заменяются пробелами, расширение отбрасывается. Например, `03_bottom_row.txt` отображается как `03 bottom row`.

### Файл, загружаемый пользователем

Пользователь может вручную ввести абсолютный путь к любому текстовому файлу. Требования:

- Файл должен быть доступен для чтения (права `r`).
- Файл не должен быть пустым.
- Размер не ограничен, но содержимое загружается целиком в оперативную память.

## 3. Интерфейс приложения

### Режим работы

Приложение работает в интерактивном полноэкранном TUI-режиме (terminal user interface) на базе библиотеки ncurses. Фонового режима и сетевого взаимодействия нет. Пользователь управляет приложением исключительно с клавиатуры.

Минимальный поддерживаемый размер терминала - 80x24 символа. При меньшем размере отображается предупреждение и ввод блокируется до тех пор, пока окно не будет увеличено. Динамическое изменение размера терминала (сигнал `SIGWINCH`, клавиша `KEY_RESIZE`) поддерживается на всех экранах.

### Цветовая схема

| Цвет | Значение |
|------|----------|
| Зелёный | Правильно введённый символ |
| Красный | Ошибка |
| Жёлтый | Текущая позиция курсора |
| Белый | Ненабранный символ / нейтральный текст |
| Голубой (cyan) | Рамки, заголовки, акцентные элементы |
| Тусклый белый | Подсказки, вспомогательные подписи |

### Экраны и их поведение

#### Главное меню

Вертикальный список из 6 пунктов с навигацией стрелками или цифрами `1`-`6`. Активный пункт подсвечивается. Подтверждение - Enter.

Пункты:
1. Lessons - список базовых уроков (Latin).
2. Languages - выбор языка программирования.
3. Practice - подменю: Normal lesson / Load File / Infinite / Timed.
4. Statistics - экран статистики.
5. Settings - экран настроек.
6. Exit - завершение.

Навигация: стрелки `up`/`dn`, цифры `1`-`6`, Enter для подтверждения, `q` или Esc для выхода из приложения.

#### Список уроков

Вертикальный список уроков выбранного набора. Навигация стрелками, выбор - Enter. Esc возвращает на предыдущий экран.

#### Экран печати (сессия)

Основной рабочий экран. Структура:

- Строка 0: горизонтальный разделитель.
- Строка 1: название урока. Если включён Hardcore - правый край строки показывает метку `[HARDCORE]` красным.
- Строка 2: горизонтальный разделитель.
- Строки 3 ... LINES-4: текст урока с подсветкой по состоянию символов.
- Строка LINES-2: аннотация спецсимволов (показывается только если текст содержит `\n` или `\t`): `$ Enter`, `> Tab` - тусклый белый.
- Строка LINES-1: строка метрик.

Строка метрик до начала ввода: `Esc - finish early`.

Строка метрик после первого нажатия: `WPM: N   Accuracy: N%   Errors: N` (слева) и `Esc - finish early` (справа). В режиме Timed дополнительно выводится обратный таймер `[NNNs]`.

Поведение при вводе:
- Верный символ - зеленеет, курсор сдвигается вправо.
- Неверный символ - краснеет, счётчик ошибок растёт, данные попадают в heatmap.
- Backspace - отменяет последний символ (недоступно в Hardcore).
- Tab - принимается если ожидается `\t`.
- Enter / KEY_ENTER - принимается если ожидается `\n`.
- Esc - досрочное завершение сессии с переходом на экран результатов.

По завершении урока (или по истечении времени в Timed) - автоматический переход на экран результатов.

#### Экран результатов

Диалоговое окно по центру экрана. Отображает: WPM, точность, количество ошибок, время сессии. Кнопки: `[R] Retry`, `[Esc] Lessons`, `[Q] Main menu`.

#### Экран статистики

Три вкладки: Overview, Heatmap, Weak Spots. Переключение стрелками `left`/`right` или клавишами `[`/`]`.

**Вкладка Overview** - список последних сессий (до 1024 записей) с пагинацией по 10, прокрутка стрелками `up`/`dn`. Вверху - лучший WPM за всё время. Внизу - подсказка клавиш.

**Вкладка Heatmap** - ASCII-визуализация QWERTY-раскладки с цветовой кодировкой ошибок: зелёный - 1-3 ошибки, жёлтый - 4-9, красный - 10 и более, белый - 0. Клавиша `R` сбрасывает данные heatmap. Esc - назад.

**Вкладка Weak Spots** - топ-10 символов с наибольшим числом ошибок. Клавиша `G` генерирует текстовое упражнение на эти символы и немедленно запускает сессию печати. Esc - назад.

#### Экран настроек

Три параметра с переключением стрелками или Enter:

| Параметр | Значения | По умолчанию |
|----------|----------|--------------|
| Hardcore | On / Off | Off |
| Mode | Normal / Timed / Infinite | Normal |
| Time Limit | 15 / 30 / 60 / 120 / 300 сек | 60 сек |

Настройки сохраняются при изменении. Esc - выход.

### Горячие клавиши (общие для всех экранов)

| Клавиша | Действие |
|---------|----------|
| `up` / `dn` | Навигация по списку / вкладкам |
| `Enter` | Подтвердить / начать |
| `Backspace` | Исправить символ (кроме Hardcore) |
| `Esc` / `q` | Назад / выйти |
| `R` | Повторить урок (экран результатов) |
| `Q` | В главное меню (экран результатов) |

## 4. Аргументы командной строки

Приложение не принимает аргументов командной строки. Запуск:

```bash
./typecode
```

или после установки:

```bash
typecode
```

## 5. Форматы хранения данных

Все файлы создаются автоматически при первом запуске. Директория `~/.typecode/` создаётся если не существует (права 0755).

### Настройки - `~/.typecode/settings.conf`

Текстовый файл, строки вида `ключ=значение`, одна запись на строку:

```
hardcore=0
mode=0
time_limit=60
```

| Ключ | Тип | Значения |
|------|-----|----------|
| `hardcore` | int | 0 - выключен, 1 - включён |
| `mode` | int | 0 - Normal, 1 - Timed, 2 - Infinite |
| `time_limit` | int | 15, 30, 60, 120 или 300 |

При наличии неизвестных строк они игнорируются. При отсутствии файла применяются значения по умолчанию.

### История сессий - `~/.typecode/stats.txt`

Текстовый файл с дозаписью (append). Каждая строка - одна сессия, поля разделены `|`:

```
timestamp|wpm|accuracy|errors|duration_sec|lesson_name
```

Пример:

```
1748012345|67|94.3|5|42|03 bottom row
```

| Поле | Тип | Описание |
|------|-----|----------|
| `timestamp` | long | Unix timestamp начала сессии |
| `wpm` | int | Слов в минуту |
| `accuracy` | float | Точность в процентах, одна цифра после запятой |
| `errors` | int | Количество ошибок |
| `duration_sec` | int | Длительность сессии в секундах |
| `lesson_name` | string | Название урока, до 127 символов |

### Данные heatmap - `~/.typecode/heatmap.txt`

Текстовый файл. Каждая строка - один символ и счётчик ошибок, разделённые `:`:

```
a:3
s:12
d:1
32:5
```

Символы с количеством ошибок 0 не записываются. Если символ печатаемый и не является `:`, записывается сам символ. Иначе - его ASCII-код в десятичном виде (например, `32` для пробела).

Файл перезаписывается целиком при каждом сохранении. Сброс heatmap клавишей `R` обнуляет файл.
