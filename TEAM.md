## О проекте

**typecode** - terminal-based тренажёр слепой печати для программистов.

Цель проекта - создать инструмент, который обучает не просто быстрой печати, а быстрому набору именно программного кода: синтаксиса языков, специальных символов, типичных конструкций.

Приложение должно ощущаться как настоящая Linux-утилита - минималистичный TUI в стиле `btop`, `lazygit`, `htop`.

**Цели разработки:**
- Глубоко изучить язык C
- Создать сильный open-source проект для портфолио
- Сделать реально полезный инструмент для программистов

**GitHub:** https://github.com/ginluv21/typecode
**GitHub Project (задачи):** https://github.com/users/ginluv21/projects/3

## Техническое задание

### Функциональность

Пользователь запускает приложение в терминале и получает интерактивный тренажёр печати. Основные сценарии использования:

- Прохождение уроков по латинским символам с нарастающей сложностью (от домашнего ряда до реального кода)
- Практика печати на конкретном языке программирования (C, Python, JavaScript, Bash, Go) - 20 уроков на каждый
- Загрузка произвольного файла с диска и его набор
- Просмотр статистики: лучший WPM, средний WPM, история сессий
- Настройка режима игры: hardcore (без Backspace), Time Attack, Infinite

### Формат входных данных

Уроки - обычные текстовые файлы `.txt`:
- `\t` - символ табуляции, отрисовывается как отступ до следующего кратного 4 столбца
- `\n` - переход на новую строку, пользователь нажимает Enter для перехода
- В остальном текст набирается посимвольно как есть

Кастомный файл: любой текстовый файл, доступный для чтения. Если файл больше 500 строк - предлагается загрузить первые 500.

Настройки читаются из `~/.typecode/settings.conf` при старте:
```
hardcore=0
mode=0
time_limit=60
```

Статистика читается из `~/.typecode/stats.txt` (CSV с разделителем `|`):
```
timestamp|wpm|accuracy|errors|duration_sec|lesson_name
```

### Интерфейс

Приложение работает в интерактивном TUI-режиме (ncurses). Не является фоновым процессом или сетевым сервисом.

**Главное меню** - рамка с ASCII-логотипом, 6 пунктов:
- Lessons - уроки latin
- Programming Languages - выбор языка, затем список уроков
- Practice - загрузка кастомного файла
- Statistics - экран статистики
- Settings - экран настроек
- Exit - выход

Навигация: стрелки вверх/вниз, цифры 1-6 для прямого выбора, Enter для подтверждения, `q` или `Esc` для выхода.

**Сессия печати** - заголовок с именем урока и режимом, текст урока с цветовой подсветкой, строка метрик (WPM, точность, ошибки, время). Зелёный - правильно, красный - ошибка, жёлтый - текущий символ.

**Экран результатов** - итоговые метрики, кнопки R (повторить) и Q (в меню).

Все экраны реагируют на изменение размера терминала в реальном времени. При размере меньше 80x24 - жёлтое предупреждение.

### Аргументы командной строки

Приложение не принимает аргументов командной строки. Запуск: `./typecode`.

### Внешние источники данных

- `~/.typecode/stats.txt` - история сессий, дозаписывается после каждого урока
- `~/.typecode/settings.conf` - настройки, перезаписываются при выходе из экрана Settings
- `lessons/` - директория с уроками, читается при каждом открытии раздела

## Архитектура

Проект построен на модульной архитектуре. Каждый модуль - отдельная пара `.c` / `.h` файлов с чёткой зоной ответственности.

```
main.c
  |
  |- ui.c       <- инициализация ncurses, resize, цветовые пары
  |- menu.c     <- главное меню, навигация
  |- lesson.c   <- загрузка урока, ввод, метрики, результаты
  |- lessons.c  <- список уроков, выбор языка программирования
  |- stats.c    <- сохранение/загрузка статистики, экран статистики
  `- settings.c <- сохранение/загрузка настроек, экран настроек
```

**Принцип взаимодействия:**
- `main.c` вызывает `ui_init()`, крутит цикл `menu_run()` и диспетчеризует по выбору
- `lessons.c` вызывает `lesson_run()` для каждого выбранного урока
- `lesson.c` вызывает `stats_save()` после завершения сессии
- Модули не вызывают друг друга за пределами этих связей

## Модули

### main.c
Точка входа. Инициализирует ncurses через `ui_init()`, загружает настройки, крутит главный цикл меню. Обрабатывает Practice (загрузка файла, валидация, запуск урока).

### ui.c / ui.h
Инициализация и завершение ncurses. Resize через `endwin()+refresh()`. Проверка минимального размера окна.

**Ключевые функции:**
- `ui_init()` - `initscr`, `cbreak`, `noecho`, `keypad`, 6 цветовых пар
- `ui_cleanup()` - `endwin()`
- `ui_on_resize()` - обработка KEY_RESIZE через `endwin()+refresh()+keypad()`
- `ui_too_small()` - проверка 80x24, показывает жёлтое предупреждение

**Цветовые константы (`include/typecode.h`):**
```c
#define COLOR_GREEN_ON_BLACK  1  // правильный символ
#define COLOR_RED_ON_BLACK    2  // ошибка
#define COLOR_YELLOW_ON_BLACK 3  // курсор / предупреждение
#define COLOR_WHITE_ON_BLACK  4  // обычный текст
#define COLOR_CYAN_ON_BLACK   5  // элементы UI
#define COLOR_BLUE_ON_BLACK   6
```

### menu.c / menu.h
Отрисовка и цикл главного меню с ASCII-логотипом.

**Ключевые функции:**
- `draw_main_menu(int selected)` - рамка, лого, пункты меню
- `menu_run()` - цикл ввода, возвращает `MenuOption`. Выход: `q`, `Q`, `Esc`

### lesson.c / lesson.h
Весь урочный стек: загрузка файла, отрисовка текста, цикл ввода, метрики, экран результатов.

**Ключевые структуры:**
```c
typedef struct {
    char *text;
    int   len;
    char  name[LESSON_NAME_MAX];
} Lesson;

typedef struct {
    int correct, errors, wpm;
    float accuracy;
    int duration_sec;
    struct timespec start;
    int started;
} Metrics;

typedef enum { CHAR_UNTYPED=0, CHAR_CORRECT, CHAR_WRONG } CharState;
typedef enum { RESULT_LESSONS=0, RESULT_REPEAT, RESULT_MAIN_MENU } ResultAction;
```

**Формула WPM:**
```
WPM = (correct / 5) / время_в_минутах
```

**Обработка спецсимволов:**
- `\t` - отрисовывается как `>`, продвижение до следующего кратного 4 столбца, пользователь жмёт Tab
- `\n` - отображается как `$`, пользователь жмёт Enter

### lessons.c
Сканирование папки с уроками, сортировка, меню выбора. Экран выбора языка программирования.

### stats.c / stats.h
Сохранение результатов сессии в `~/.typecode/stats.txt`. Загрузка истории. Экран статистики с прокруткой.

### settings.c / settings.h
Хранение настроек: hardcore, mode (Normal/Timed/Infinite), time_limit_sec. Сохранение в `~/.typecode/settings.conf`.

## Формат файлов уроков

Обычный текстовый файл `.txt`. Каждый файл - один урок.

- Отступы через `\t` (символ табуляции)
- Переход строки через `\n`
- Именование: `NN_название.txt` где NN - двузначный номер для сортировки

**Пример** (`lessons/latin/01_home_row.txt`):
```
asdf jkl; asdf jkl; fjfj dkdk slsl aaaa
```

**Пример** (`lessons/c/05_functions.txt`):
```
int add(int a, int b) {
	return a + b;
}
```

## Формат хранения данных

Все данные хранятся в `~/.typecode/`:

```
~/.typecode/
|- stats.txt        # история сессий
|- heatmap.txt      # статистика ошибок по символам
`- settings.conf    # настройки пользователя
```

**stats.txt** - CSV с разделителем `|`:
```
1716000000|74|97.5|2|42|05 functions
```
Поля: `timestamp|wpm|accuracy|errors|duration_sec|lesson_name`

**settings.conf:**
```
hardcore=0
mode=0
time_limit=60
```
Режимы: 0 - Normal, 1 - Timed, 2 - Infinite.

## Соглашения по коду

### Именование
- Функции: `module_action()` - `stats_save()`, `lesson_run()`
- Структуры: PascalCase - `SessionResult`, `Settings`
- Константы: UPPER_SNAKE - `COLOR_CYAN_ON_BLACK`, `MAX_LESSONS`
- Переменные: snake_case - `best_wpm`, `lesson_path`

### Файлы
- Каждый модуль - пара `.c` / `.h`
- В `.h` только объявления, никакой реализации
- Include guard в каждом `.h`:
```c
#ifndef MODULE_H
#define MODULE_H
// ...
#endif
```

### Память
- Каждый `malloc` имеет соответствующий `free`
- Проверять возвращаемое значение `malloc` на NULL

### Стиль
- Отступы: Tab (`\t`)
- Открывающая скобка на той же строке: `if (x) {`
- Максимальная длина строки: 100 символов

## Git workflow

### Ветки
- `main` - стабильная версия
- `feature/название` - новая фича
- `fix/название` - исправление бага

### Коммиты

Типы: `feat`, `fix`, `refactor`, `docs`, `style`, `test`

```
feat: add typing engine with real-time metrics
fix: correct WPM calculation on fast input
docs: update README with installation steps
```

### Pull Requests
- Каждая задача из issues - отдельный PR
- PR должен закрывать issue: `Closes #7` в описании
- Код ревью минимум одного участника перед мержем

## Сборка и запуск

```bash
# Ubuntu / Debian
sudo apt install gcc libncurses-dev make

# Arch
sudo pacman -S gcc ncurses make

# Fedora
sudo dnf install gcc ncurses-devel make
```

```bash
make            # сборка
make run        # сборка и запуск
make debug      # сборка с AddressSanitizer
make test       # запуск тестов
make coverage   # тесты + отчёт покрытия
make clean      # очистка артефактов
```
