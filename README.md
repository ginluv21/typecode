## Что такое typecode?

typecode - это TUI-тренажёр печати, созданный специально для программистов. В отличие от обычных тренажёров, typecode обучает набору настоящего кода - синтаксиса, паттернов и конструкций тех языков, которые ты используешь каждый день.

Ощущается как настоящая Linux-утилита, а не игрушка. Представь `btop`, `lazygit`, `htop` - но для прокачки скорости набора кода.

**Чему ты учишься:**
- Слепая печать (без взгляда на клавиатуру)
- Быстрый набор программного синтаксиса
- Мышечная память на конструкции языков
- Специальные символы: `{}`, `[]`, `()`, `<>`, `;`, `->`, `=>`, `::`, `&&`, `||`

## Возможности

### MVP
- TUI главное меню с навигацией клавишами
- Движок печати с мгновенной обратной связью (зелёный / красный / жёлтый курсор)
- Метрики в реальном времени: WPM, точность, количество ошибок
- Уроки загружаются из обычных текстовых файлов
- 5 базовых уроков (домашний ряд, верхний, нижний, цифры, символы)
- Экран результатов после каждой сессии

### v1.0
- 20 уроков с нарастающей сложностью
- Режим Programming Languages: C, Python, JavaScript, Bash, Go - по 20 уроков на каждый язык
- Загрузка любого файла с диска прямо из меню
- Статистика между сессиями (лучший WPM, история, точность)
- Hardcore режим - Backspace отключён
- Режимы практики: Time Attack (15-300 сек) и бесконечный режим
- Экран настроек с сохранением конфигурации в `~/.typecode/settings.conf`
- Динамический resize терминала на всех экранах
- Предупреждение при размере окна меньше 80x24
- Выход из приложения на `q` или `Esc`

### v2.0+ (в планах)
- Heatmap клавиатуры - видишь на каких клавишах больше всего ошибок
- Уроки на кириллице / русском языке
- Vim mode навигация (`hjkl`)
- Speed Challenge с рангами (S / A / B / C)
- Анимированный splash screen при запуске
- Man page

## Установка

### Требования

| Инструмент | Назначение | Обязателен для |
|------------|------------|----------------|
| GCC | Компилятор | `make`, `make test`, `make coverage` |
| libncurses-dev | TUI библиотека | `make`, `make test`, `make coverage` |
| Python 3 + gcovr | Отчёт покрытия | `make coverage` |

### Установка зависимостей

```bash
# Ubuntu / Debian
sudo apt install gcc libncurses-dev python3-pip
pip3 install gcovr

# Arch
sudo pacman -S gcc ncurses python-pip
pip3 install gcovr

# Fedora
sudo dnf install gcc ncurses-devel python3-pip
pip3 install gcovr
```

### Сборка из исходников

```bash
git clone https://github.com/ginluv21/typecode.git
cd typecode
make
./typecode
```

## Структура проекта

```
typecode/
- src/
  - main.c        # Точка входа, Practice load-file, главный цикл меню
  - ui.c          # Инициализация ncurses, resize, цветовые пары
  - menu.c        # Главное меню, навигация
  - lesson.c      # Движок печати, уроки, экран результатов
  - lessons.c     # Список уроков, выбор языка
  - stats.c       # Статистика: сохранение, загрузка, экран
  - settings.c    # Настройки: сохранение, загрузка, экран
- include/
  - typecode.h    # Общие константы и типы
  - ui.h
  - menu.h
  - lesson.h
  - stats.h
  - settings.h
- lessons/
  - latin/        # 20 базовых уроков (домашний ряд -> финал)
  - c/            # 20 уроков C (variables -> final)
  - python/       # 20 уроков Python
  - javascript/   # 20 уроков JavaScript
  - bash/         # 20 уроков Bash
  - go/           # 20 уроков Go
- tests/          # Тесты (33 теста)
- build/          # Артефакты сборки (gitignore)
- Makefile
- README.md
```

## Цели Makefile

```bash
make            # Собрать проект
make run        # Собрать и запустить
make debug      # Сборка с -g -fsanitize=address,undefined
make test       # Запустить все тесты
make coverage   # Тесты + отчёт покрытия (минимум 60%)
make check-deps # Проверить наличие зависимостей
make clean      # Удалить артефакты сборки
```

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `up` / `dn` | Навигация по меню |
| `1`-`6` | Прямой выбор пункта |
| `Enter` | Подтвердить |
| `Backspace` | Исправить последний символ |
| `Esc` / `q` | Выйти / назад |
| `R` | Повторить урок |
| `Q` | Вернуться в меню |
